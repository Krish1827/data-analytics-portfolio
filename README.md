# data-analytics-portfolio

## Overview
This repository serves as a centralized portfolio of my data analytics work.
It highlights hands-on projects where I analyze real-world datasets, clean and
validate data, design SQL queries, and produce insights that support
data-driven decision-making.

development, databases, and networking. I am building my career in data
analytics and analytics engineering, with a strong interest in working with
data at scale and across different domains.
