# Plant Co. Performance Dashboard (Power BI)

## 📌 Project Overview
This project analyzes Plant Co.'s sales and performance data using Power BI.
The goal is to provide clear insights into monthly trends, KPIs, and year-over-year performance.

## 🛠 Tools & Technologies
- Power BI
- Excel / CSV
- SQL (for data cleaning)
- DAX (time intelligence measures)

## 📊 Key Features
- Sales trend analysis (monthly)
- Year-over-Year (YoY) comparison
- KPI cards for revenue and growth
- Interactive slicers (Year, Month)

## 📂 Dataset
- Raw data cleaned using SQL and Power Query
- Final dataset included in `/data/processed`

## 🚀 How to Use
1. Download the `.pbix` file from `/powerbi`
2. Open in Power BI Desktop
3. Refresh data if needed

## 📈 Business Insights
- Sales show strong growth in Q2
- Seasonal dips observed in early months
- YoY performance improved compared to previous year
