# SQL COVID-19 Data Analysis

## Overview
This project analyzes global COVID-19 data using SQL to uncover trends in cases, deaths, and vaccinations.

## Objectives
- Analyze infection and death rates across countries and continents
- Track vaccination progress using window functions
- Practice real-world SQL analytics techniques

## Tools & Skills
- SQL Server (SSMS)
- Joins, CTEs, window functions
- Aggregations, temp tables, views

## Dataset
Public COVID-19 datasets (cases, deaths, vaccinations)

## Key Insights
- Countries with highest infection rates relative to population
- Rolling vaccination trends by location
- Global death percentage trends
