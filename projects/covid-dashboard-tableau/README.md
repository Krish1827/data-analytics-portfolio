# COVID-19 Dashboard Project

This project analyzes COVID-19 data using SQL, Excel, and Tableau. It provides insights on cases, deaths, and infection rates across countries and continents.

## Contents
- **SQL**: Queries used to extract and transform data from the database.
- **ExcelData**: Exported query results in Excel.
- **Tableau**: Tableau workbook for dashboard visualization.
- **Links**: Tableau Public link.

## Queries
1. Total cases, total deaths, and death percentage by continent.
2. Total deaths for locations not part of a continent.
3. Percent population infected per country.
4. Percent population infected over time per country.
